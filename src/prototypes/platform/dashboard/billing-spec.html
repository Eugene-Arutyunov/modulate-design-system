Layout

Page states

Each state links to the prototype in that state. The widget title stays in every state. Tags, banners and the balance card buttons are hidden while loading or on error.

StateRendering
{{ proto('Loading', data='loading') }}{{ ds('m__skeleton') }} in the shape of the content. Balance: one large bar and two rows of small bars. Alerts: two rows with a button. Tables: real headers, four rows of bars. Charts: their own grid, pulsing.
{{ proto('Empty', data='empty') }}Balance: 0.00 with the purchase buttons ({{ proto('Metered', type='metered', data='empty') }}: full included credits and its rows). Alerts: same rows, “No thresholds yet.” Tables: headers and one centered caption line, no Filter or Export. Charts: axes and grid, no data.
{{ proto('Error', data='error') }}{{ ds('m__widget__placeholder') }}: “Couldn’t load data” in caption colour, centered, with {{ ds('m__button-secondary-outline.S') }} “Try again”. Tables and charts use the large placeholder.
{{ proto('Page error', data='page-error') }}One widget instead of all blocks: large placeholder, at least 18rem tall, same text and button.

Modes

Customer type changes the balance card:

  • {{ proto('Contracting') }}: Used this period, Renews; buttons Buy Credits and Apply Credit Code.
  • {{ proto('Pay/Go', type='paygo') }}: Used since last top-up, Last top-up; the same two buttons.
  • {{ proto('Metered', type='metered') }}: Included credits used, Estimated overage ({{ proto('once used up', type='metered', scenario='now-metered') }}), Next invoice, Monthly commitment; no buttons.

  • View, Filter and Export stay.
